# Straw Bed 🌾🛏️ (Minecraft 1.21.4 Fabric Port)

Неофициальный порт и обновление мода **Straw Bed** для **Minecraft 1.21.4 (Fabric)** от **byMr712**.

Оригинальный автор мода: [gvoze32](https://github.com/gvoze32) ([Modrinth](https://modrinth.com/mod/straw-bed) / [CurseForge](https://www.curseforge.com/minecraft/mc-mods/straw-bed)).

---

## 📖 О моде

**Straw Bed** добавляет в игру простую и дешевую одноразовую кровать из соломы (пшеницы), идеально подходящую для первых ночей выживания или длительных путешествий.

### Особенности:
- 🌾 **Дешевый крафт**: создается всего из 3 снопов сена (пшеницы) и 3 досок.
- 💤 **Пропуск ночи без сброса спавна**: соломенная кровать позволяет пропустить ночь, **не перезаписывая точку возрождения (spawn point)** игрока!
- 🍂 **Одноразовое использование**: после пробуждения кровать разрушается и издает шуршащий звук соломы.
- 📊 **Кастомная статистика**: отслеживание количества использованных соломенных кроватей в статистике игрока.

## 🛠️ Что изменено в порте для 1.21.4 (byMr712)

- ⚡ **Обновление под Minecraft 1.21.4 & Fabric Loader**:
  - Миграция на Fabric Loom 1.10.1, Yarn маппинги `1.21.4+build.7` и Java 21 LTS.
  - Адаптация под новые сигнатуры `Block.Settings` (`RegistryKey<Block>`, `RegistryKey<Item>`).
  - Миграция регистрации предметов и блоков через единый реестр `Registries.BLOCK` и `Registries.ITEM`.
  - Добавление в креативную вкладку `ItemGroups.FUNCTIONAL` через `ItemGroupEvents`.
- 🎨 **Клиентские определения предметов (Client Item Definitions)**:
  - Добавлен `assets/strawbed/items/straw_bed.json` в соответствии со стандартом Minecraft 1.21.4 для корректного отображения иконки в инвентаре и руке.
- 🌐 **Полная двуязычная локализация**:
  - Полная поддержка русского (`ru_ru.json`) и английского (`en_us.json`) языков для блоков, статистики и сообщений о сне.

## 📦 Сборка и установка

1. Требуется **Java 21** и **Fabric Loader** для Minecraft 1.21.4.
2. Для сборки из исходников запустите:
   ```bash
   ./gradlew build
   ```
   или `build.bat` на Windows.
3. Готовый jar-файл будет находиться в `build/libs/StrawBed-1.21.4-byMr712.jar`.
